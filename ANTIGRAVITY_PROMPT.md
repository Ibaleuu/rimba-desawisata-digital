# Prompt handoff Antigravity

Lanjutkan project Rimba di folder `desawisata-digital` sebagai web DesaWisata Digital sesuai Studi Kasus 3. Sebelum mengubah, baca `README.md`, `WORKFLOW_7_PLATFORM.md`, dan issue Linear DW yang terkait. Pertahankan bahasa Indonesia, desain responsif, dan identitas visual yang sudah ada.

Fokus produk: katalog destinasi, detail aktivitas/fasilitas/musim, paket wisata, permintaan reservasi, etalase produk UMKM, portal pengelola untuk ringkasan, reservasi, CRUD konten, dan pesan UMKM. Reservasi harus tetap berstatus menunggu konfirmasi sampai pengelola memverifikasi tanggal dan kapasitas secara manual. Jangan menambah pembayaran daring atau menyatakan ketersediaan otomatis.

Pertahankan struktur HTML/CSS/JS vanilla kecuali ada alasan teknis kuat dan jelaskan migrasi terlebih dahulu. Jangan kirim nama, nomor WhatsApp, tanggal persis, catatan, atau isi pesan ke analytics. Gunakan event Rimba yang sudah ditentukan di dokumen workflow. Jalankan hanya pemeriksaan yang diminta issue; catat hasil dan perubahan. Untuk setiap perubahan, sebutkan issue DW, file yang disentuh, dan langkah review manual. Jangan membuat klaim bahwa backend, login admin, atau sinkronisasi lintas perangkat sudah tersedia.
